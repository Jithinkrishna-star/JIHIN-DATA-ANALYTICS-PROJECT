# 📊 Data Analytics Portfolio Projects

Welcome to my Data Analytics repository! This repository showcases end-to-end data cleaning, modeling, querying, and interactive dashboarding across **Power BI**, **Excel**, **SQL**, and **Tableau**.

## 🛠️ Tools & Technologies Used
* **Business Intelligence & Visualization:** Power BI, Tableau Public, Microsoft Excel

---

## 📂 Repository Structure

### 1. 📈 Power BI — Sales & E-Commerce Analytics Dashboard
* **Folder:** `/POWER BI`
* **Overview:** Designed an interactive executive dashboard analyzing 50K total orders and ₹3.48M in net revenue across product categories, payment statuses, and cities.
* **Key KPIs Tracked:** Total Orders (`50K`), Net Revenue (`₹3.48M`), Return Rate (`3.07%`), and Average Order Value (`₹75.73`).
* **Highlights:**
  * Built dynamic date range (`OrderDate`), `Payment Status`, and `Category` slicers for real-time filtering.
  * Visualized monthly net revenue trends, category-level performance (led by Electronics at ₹1.76M), payment distribution (`93.13%` Paid), and top-performing cities.

---

### 2. 📉 Excel — IPL MATCHES ANALYTICS DASHBOARD

* **Highlights:** Automated report summaries and structured visual layouts for quick executive insights.

### 3. 🗄️ SQL — MOBILE_SALES_DATA

### 4. 📊 Tableau — EXECUTIVE HR & PROMOTION ANALYTICS
